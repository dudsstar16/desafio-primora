# Trabalhar no projeto Primora

Inicie os chats deste projeto na pasta do clone de [dudsstar16/desafio-primora](https://github.com/dudsstar16/desafio-primora/tree/main). Use português simples para explicar as decisões à equipe.

## Ao abrir um chat

- Confira a raiz, o remoto, a branch e o estado do Git. Implemente cada objetivo em uma branch própria e preserve o trabalho em andamento.
- Use os [requisitos oficiais](https://github.com/dudsstar16/desafio-primora/tree/main/docs/requisitos) como referência. Consulte o PDF pertinente à tarefa e valide o comportamento atual no código e nos testes.
- Neste computador, leia `memoria/00_INDICE_MEMORIA.md`, consulte a data de `memoria/99_ESTADO_ATUAL_PROJETO.md` e abra a nota do objetivo em andamento. Mantenha a memória local fora do Git. Quando a pasta estiver ausente, avise e prossiga com os requisitos, o README e o código.

## Antes de cada etapa

- Apresente o objetivo, como verificar a entrega e uma sugestão de modelo e esforço. Espere a pessoa confirmar ou ajustar a escolha antes de iniciar planejamento, implementação de cada frente, testes e publicação. Aproveite a confirmação já dada para a etapa atual.
- Quando a skill `orchestrate` estiver disponível, aplique-a e avalie se partes independentes justificam o custo de subagentes.
- Ao concluir, descreva o resultado, as verificações realizadas e o que ficou pendente. Registre o andamento do objetivo na nota local quando disponível.

## Regras da aplicação

As consultas de clientes e vendedores são públicas. A manutenção exige autenticação Django/DRF. Os registros individuais da auditoria ETL ficam no Django Admin. A apresentação usa a rota `/`. O objetivo do dashboard operacional está na nota local `memoria/11_DASHBOARD_OPERACIONAL_HIBRIDO.md`.
